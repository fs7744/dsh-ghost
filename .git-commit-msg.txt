feat(extension): 扩展驱动当前标签页（页面桥）

- 补上「扩展不自动带页面内容」的缺口：扩展用 chrome.debugger 驱动**用户当前标签页**，
  与宿主之间加一条命令通道（模型排队 → 扩展轮询取 → CDP 执行 → 回传唤醒模型）。
- 新模型工具：page_read（标题/网址/可见文本）、page_click（可见文字或 CSS 选择器）、
  page_fill、page_screenshot（base64 回传后宿主落盘到工作区）。
- 扩展在发消息前自动刷新页面快照并上报，模型因此知道「当前页面」是什么。
- 队列改为 pending + inflight 两段：命令被取走仍在途，回传才能唤醒等待方。
- 安全：走 CDP 而非注入脚本（页面看不见我们），但保留浏览器「正在被调试」提示条；
  只在用户发消息时采集页面内容；只作用于当前活动标签页。
- 验证：626 用例、local 21/21、7/7 门禁、插件宿主验收通过；docs/EXTENSION.md 补 §1.5。
